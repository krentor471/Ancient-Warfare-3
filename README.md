# Ancient Warfare 3

Неофициальное продолжение Ancient Warfare 2 для Minecraft 1.20.1 (Forge).
Основано на коде [Ancient Warfare 2: Remastered](https://www.curseforge.com/minecraft/mc-mods/ancient-warfare-2-remastered) 0.2.8,
который, в свою очередь, основан на Ancient Warfare 2 от shadowmage45 и P3pp3rF1y.

Цель: реалистичный средневековый мод, где игрок правит своей фракцией. Рабочие, логистика,
технологии и осада из AW2, RTS-управление армией, живые жители, дипломатия с ИИ-фракциями.
Без магии и фэнтези.

## Состояние

Исходники получены декомпиляцией jar-файла Remastered 0.2.8 (Vineflower 1.10.1) и переведены
на официальные имена Mojang. Магия, фэнтези-расы и интеграции с фэнтези-модами удалены;
остались 20 человеческих фракций AW2.

Сборка и запуск (Java 17):

```
./gradlew build        # jar в build/libs
./gradlew runClient    # клиент для тестов
./gradlew runServer    # выделенный сервер
```
